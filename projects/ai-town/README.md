# 实战项目：晨光 AI 小镇

[仓库首页](../../README.md) · [第一次打开](../../START_HERE.md) · [五阶段路线](../../topics/agent-systems/ROADMAP.md) · [实际界面截图](../../assets/ai-town-preview.png)

三位居民住在同一座小镇里。每位居民有职业、目标、所在地点和精力；推进时间，可以观察他们工作、休息、相遇，以及留下的近期记忆。

**当前版本：阶段 1，规则驱动教学骨架。** 行动由 Python 条件判断决定，聊天使用固定文案，没有调用大模型，不需要 API 密钥。工程演示存在，不代表学习者已经通过阶段 1。

## 启动网页

需要 Python 3.10 或更新版本，仅用标准库，无第三方依赖。

Mac 可以双击本目录的 `start-mac.command`；Windows 可以双击 `start-windows.bat`。启动入口会选择空闲端口并自动打开浏览器，具体操作见[第一次打开](../../START_HERE.md)。

也可以从仓库根目录运行：

```bash
python3 projects/ai-town/server.py --open-browser
```

默认监听 `127.0.0.1:8765`，在**运行程序的同一台电脑**上访问终端显示的地址。云端程序不会自动映射到自己电脑的 localhost。端口被占用时加 `--port 0` 自动选择空闲端口。终端按 `Ctrl+C` 停止。

所有访问者共享当前进程中的同一个小镇，本项目用于个人本地学习。

## 网页操作

- **推进一轮**：小镇时间前进 30 分钟，居民依次执行一个动作。
- **自动运行 / 暂停**：连续观察，默认最多 24 轮。
- **选择居民**：查看状态、行动前的观察、行动原因和近期记忆。
- **重置小镇**：清空当前运行记录，重新读取 `world.json`；修改配置后用它开始新实验。

地点包括咖啡馆、图书馆、广场、居民小屋和公园。当前在地点之间直接移动，没有逐格寻路和碰撞系统。

## 第一课：只改变一个数字

本次目标是认识“状态会影响决策”。先保留小林的 `energy: 75`，重置后推进一轮，记录行动、地点和精力。然后只把这个数改为 `20`，保存文件，先预测，再重置并推进相同的一轮。

**两次都从第 0 轮开始，只改一个参数。** 把预测与实际结果写进[学习记录](../../topics/agent-systems/README.md#学习记录)。现在不必读懂整个程序，也不把这项小练习视为整个阶段已过关。

## 从小镇理解 Agent

```text
世界状态 → observe()：我看到了什么
                ↓
       choose_action()：下一步做什么
                ↓
       apply_action()：校验并执行行动
                ↓
         世界更新 + 事件记忆
                └────────→ 下一轮观察
```

模型将在第二阶段接入决策部分；程序继续负责检查和执行行动。当前 `goal` 仅是角色设定的展示文字，规则不会自动理解它。决策实际使用精力、地点、职业地点和近期打招呼记录。

每轮居民按配置顺序依次行动，后行动的居民能看到前面行动造成的变化。侧栏的“行动前的观察”可能与行动后的当前位置不同。

每人最多保留 12 条自己的近期事件。另有一份按居民 ID 记录的最近交谈轮次，用于判断能否再次找同一个人聊天。这些记录都存在内存中，重置或服务重启会清空。长期记忆检索和存读档是后续阶段的目标。

## 第二课：记住跟谁聊过

在不需要优先回家或休息时，NPC 会逐个检查附近的人：距离上次与这个人交谈不足 4 轮就跳过，继续检查下一人；没有聊过或已间隔至少 4 轮，就选择与这个人交谈。如果没有可聊天的人，则继续判断前往工作地点、工作等行动。

“轮”是世界轮次，每轮为 30 分钟模拟时间。同一轮中，每位 NPC 各选择一次行动；交谈没有额外的内部轮次。比如第 6 轮和阿岚聊过，第 8 轮仍不能再次找他，第 10 轮就可以；这不限制期间与其他人聊天。

每次成功交谈，双方都更新自己的 `last_chat_ticks`，并在交谈事件中保存对方的 `partner_id`。这个字典记录“对方 ID → 最近交谈轮次”，不会因为最近 12 条事件被裁剪而提前忘记间隔。

选择对象的关键代码在 [town.py](town.py) 的 `choose_action()`：

```python
for person_id in observation["nearby_ids"]:
    last_chat_tick = observation["last_chat_ticks"].get(person_id)
    if last_chat_tick is not None and observation["tick"] - last_chat_tick < 4:
        continue
    return {"type": "talk", "target": person_id,
            "reason": "附近有居民，且最近四轮内没有与对方交谈，打个招呼。"}
```

`for` 逐个查看附近居民；`.get()` 查上次交谈轮次，没有记录时得到 `None`；`continue` 跳过当前居民，检查下一位；`return` 选定一个动作并结束本次选择。Python 的 `pass` 只是占位语句，不会跳过当前居民。

从默认配置启动后，推进一轮并查看行动记录：小林先找阿岚，阿岚接着跳过小林、找小乔，小乔再跳过阿岚、找小林。同一轮可以参与不同对象的交谈，但每人仍只主动选择一次行动。精力不足时，回家或休息的规则仍然优先。

修改 `town.py` 后，停止并重新启动服务，使用新打开的页面；仅点击网页上的“重置小镇”不会重新加载 Python 代码。本机若做过精力参数或规则实验，更新文件前先保留自己的修改。
