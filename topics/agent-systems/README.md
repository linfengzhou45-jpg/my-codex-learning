## 我的目标

从零基础开始，独立完成一个可运行的虚拟 AI 小镇：NPC 能观察身边的事，根据角色、目标和个人记忆用模型决定下一步，生成对白，并通过程序支持的动作改变世界。随后让模型提出短期目标、形成多步计划，并根据行动结果调整。

## 初次入门练习

尚未运行过小镇时，打开[项目说明中的首次练习](../../projects/ai-town/README.md)，按其中的实际命令运行。入门任务是：**修改一个 NPC 的一个数据字段，再运行并观察变化。** 这项规则练习不需要模型 API 账号；已经完成后按上方当前学习重点继续。

修改前记下原值和自己的预测，修改后保存关键输出。然后试着解释：这个字段由哪段规则读取，又怎样影响了角色行为？先写自己的理解，再让 AI 检查；不要一次修改多个字段。

可以对 AI 说：

> 我从零开始，用 AI 小镇学习 Agent。今天只改一个 NPC 的一个数据字段并观察运行结果。请先解释完成这一步所需的最少概念，让我尝试。等我交出修改和输出后，一次只问一道题，检查我能否讲清数据怎样影响行为，不提前给出完整答案。

首次小练习只验证一项能力，不等于整个阶段 1 已过关。
