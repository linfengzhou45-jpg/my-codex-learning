## 我的目标

从零基础开始，独立完成一个可运行的虚拟 AI 小镇：NPC 能观察身边的事，用模型决定下一步，通过程序允许的行动改变世界，与其他角色交流，并记住自己的经历。

先用 Python、JSON 和命令行理解程序，再接入模型。图形界面帮助观察；模型怎么决定、程序怎么执行、结果怎么反馈，是学习的主线。

**当前起点：阶段 1，学习者能力尚待验证。** 本轮搭建规则驱动的教学骨架，尚未接入大模型，不能把当前 NPC 称为已经实现的 AI 自主角色。后续功能及评测详见路线；代码存在不代表学习者已经过关。

## 第一轮学习怎么开始

打开[项目说明中的首次练习](../../projects/ai-town/README.md)，按其中的实际命令运行。今天只做一个任务：**修改一个 NPC 的一个数据字段，再运行并观察变化。** 具体字段与操作以项目说明为准；现在不需要模型 API 账号。

修改前记下原值和自己的预测，修改后保存关键输出。然后试着解释：这个字段由哪段规则读取，又怎样影响了角色行为？先写自己的理解，再让 AI 检查；不要一次修改多个字段。

可以对 AI 说：

> 我从零开始，用 AI 小镇学习 Agent。今天只改一个 NPC 的一个数据字段并观察运行结果。请先解释完成这一步所需的最少概念，让我尝试。等我交出修改和输出后，一次只问一道题，检查我能否讲清数据怎样影响行为，不提前给出完整答案。

首次小练习只验证一项能力，不等于整个阶段 1 已过关。

## 学习记录

每次学习后复制下面的模板，填写真实结果。保留自己的原始预测和解释，即使它们后来证明不对。

```markdown
### 日期 / 阶段 / 本次小目标

- 我要解决的问题：
- 修改前的预测：
- 我实际做了什么（原值 → 新值）：
- 运行命令与关键输出：
- 练习代码或笔记位置：
- 预测与实际有什么不同：
- 我用自己的话解释原理：
- AI 检查发现的错误或遗漏：
- 我如何修正并重新验证：
- 对照本阶段标准：已验证哪些，还缺哪些：
- 下次只做的一件事：
```

## 过关时怎么用 AI

> 请根据本主题路线中阶段【编号】的能力标准检查我的学习证据。逐项区分“已经验证”“还未验证”“实际失败”。一次只安排一道问题或一项操作，等我完成后再给反馈。不要仅凭代码存在、我说看懂了，或由你代做的结果判断我已经掌握。

六种方法继续用于整个项目：按阶梯定位，聚焦一个小任务，逐题检查理解，阶段练习后写一页速查，只保留真正使用的资源，并用自己的话复述程序原理。
